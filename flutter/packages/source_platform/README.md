# source_platform

Android platform plugin generated with the official Flutter plugin template. Provides source-isolated preferences and CookieManager access for the Dart source engine. Browser verification is handled by the containing Android application through the source host channel.

See the [Android Reference](../../docs/reference/v1/android.md) for application integration, browser task cancellation and Cookie boundaries. This plugin does not migrate Room data or provide continuous HTTP/WebView Cookie synchronization.

Run `flutter analyze` and `flutter test` from this package. Device behavior is a separate validation step.
